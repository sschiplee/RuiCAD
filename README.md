# RuiCAD · 开源全屋定制 CAD 工具箱

一套面向**全屋定制 / 板式家具设计师**的免费开源 AutoCAD 插件，用纯 AutoLISP 实现，
覆盖柜体框架、板件部件、门板抽屉、五金孔位、假三维轴测、一键/连续标注、拆单统计、智能编辑等高频绘图场景。
**无需注册、无需登录、无需联网、无机器绑定**，装上即用，也可自由二次开发。

> 协议：MIT License　|　兼容：AutoCAD 2007+、中望 CAD、浩辰 CAD（AutoLISP 环境）
> 版本：v0.2.0　|　命令数：46 个（自测 47/47 通过）

---

## 一、特性

- **46 个绘图命令**，两个字母即可调用，贴合中文设计师习惯（KJ 框架、DG 标准柜、MD 门板、CY 抽屉、JL 铰链、SYH 三合一排孔……）
- **参数化**：板厚、门缝、踢脚、层板数、门板数、铰杯径、系统孔距等全部可在 `RC` 命令或 `settings.lsp` 里按本厂工艺调整
- **独立图层体系**：柜体/内部/门板/五金/灯带/标注/辅助/文字 自动分层分色，不污染现有图纸
- **一键标注 / 逐段连续标注 / 门板标注 / 面积 / 拆单 BOM（含板件尺寸、线长、孔数）导出 CSV**
- **五金孔位**：铰链按门高自动定数定距、拉手、32mm 三合一系统排孔
- **假三维轴测、俯视投影（自动识别内部竖板）、剖切、大样放大**
- **智能编辑**：KS 智能拉伸、QL 清理零长度/重合线段、TC 区域填充
- 纯 AutoLISP，**不依赖任何运行库、不联网、不收集数据**
- 提供**图形化安装程序（单文件 exe）**，双击自动检测并配置 CAD；安装时若 CAD 正开着会**即时加载、无需重启**，也可干净卸载

## 二、安装

### 方式 A：安装程序（推荐，双击即用）

1. 双击 `RuiCAD-Setup.exe`；
2. 选择安装位置（默认 `%LOCALAPPDATA%\RuiCAD`，**无需管理员权限**）；
3. 点"立即安装"，安装器会自动：
   - 释放插件文件；
   - 检测本机所有 AutoCAD / 中望 / 浩辰配置档案；
   - 把插件加入"支持文件搜索路径"和"启动套件（开机自动加载）"；
   - 若 CAD 已打开，立即向当前图纸注入加载，**不用重启 CAD**；
4. 打开 CAD，命令行输入 `RCH` 能看到命令表即成功。

卸载：Windows「设置 → 应用」或安装目录下 `RuiCAD-Uninstall.exe`，自动清理注册表与文件。

### 方式 B：手动加载（免安装 / 临时使用）

1. CAD 命令行输入 `APPLOAD`（或"加载应用程序"）；
2. 选择本项目根目录的 `init.lsp`，加载；
3. 如需每次启动自动加载，把 `init.lsp` 加入 APPLOAD 的"启动套件"即可。

## 四、工艺参数配置

命令 `RC` 可交互修改常用项；也可直接编辑 `core/settings.lsp`（改完重新加载即生效）：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `*rc-thk*` | 18 | 常规板材厚度 mm |
| `*rc-back-thk*` | 9 | 背板厚度 |
| `*rc-gap*` | 2 | 门缝 / 板缝 |
| `*rc-plinth*` | 100 | 踢脚高度 |
| `*rc-rod-d*` | 32 | 衣杆直径 |
| `*rc-depth*` | 600 | 柜体默认深度（轴测/俯视） |
| `*rc-door-num*` | 2 | 默认门板数 |
| `*rc-shelf-num*` | 3 | 默认层板数 |
| `*rc-hinge-cup*` | 35 | 铰链铰杯直径 |
| `*rc-hinge-edge*` | 100 | 铰杯距门顶/门边距离 |
| `*rc-cam-pitch*` | 32 | 三合一 / 系统孔孔距 |
| `*rc-cam-d*` | 5 | 系统孔直径 |
| `*rc-handle-len*` | 128 | 默认拉手长度 |
| `*rc-dim-txt*` | 35 | 标注文字高度 |

## 七、二次开发

- 所有命令都是 `c:XX` 函数，核心逻辑是 `rc:xxx` 纯函数（传入点和参数即可绘图），便于复用与单测；
- 新增命令：在 `commands/` 下新建 `.lsp`，并在 `init.lsp` 与安装器 `Setup.cs`/`build.bat` 的文件清单里同步登记；
- 新增图层/参数：改 `core/settings.lsp`；
- 几何范围选择统一用 `rc:lines-in-box`（基于 `ssget _X` + 包围盒判断，不依赖屏幕窗口，无头/交互均稳定）；
- 代码仅使用最基础的 `entmake` / `command`，兼容老版本与国产 CAD。

### 自测

`test/` 提供基于 `accoreconsole.exe` 的无头测试：设置 `RC_ROOT` 后运行 `run_tests.bat`，
`test_main.lsp` 逐个调用核心函数，断言"无 LISP 错误 + 正确生成图元"，当前 **47/47 全部通过**。
